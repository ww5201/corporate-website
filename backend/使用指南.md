##  下一步操作

### 1️ 注册 MongoDB Atlas (免费)

1. 访问：https://www.mongodb.com/cloud/atlas/register
2. 使用邮箱注册账号
3. 创建免费集群 (M0 - 512MB 存储)
4. 创建数据库用户 (记住用户名和密码)
5. 获取连接字符串 (Connection String)

### 2️⃣ 配置数据库连接

编辑文件：`D:\tokai\backend\.env`

将连接字符串替换为你的：
```env
MONGODB_URI=mongodb+srv://<你的用户名>:<你的密码>@cluster0.xxxxx.mongodb.net/luxury-co
```

### 3️⃣ 本地测试运行

在 `D:\tokai\backend` 目录下运行：
```bash
npm run dev
```

如果看到 `✅ MongoDB 连接成功` 和 `服务器运行在 http://localhost:3000`，说明成功！

### 4️⃣ 打开后台管理界面

直接用浏览器打开：`D:\tokai\backend\admin.html`

##  部署到互联网 (免费)

### 部署后端到 Vercel

1. 安装 Vercel CLI:
   ```bash
   npm install -g vercel
   ```

2. 登录并部署:
   ```bash
   cd D:\tokai\backend
   vercel login
   vercel
   ```

3. 在 Vercel 控制台添加环境变量 `MONGODB_URI`

### 更新前端网站 API 地址

修改前端代码中的 API 地址为 Vercel 部署的 URL
