# 精致奢华企业官网

高品质黑金风格企业官网，基于 Vite 构建。

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物在 `dist/` 目录，可以直接部署。

## 部署到 GitHub Pages

1. 将代码推送到 GitHub 仓库
2. 在仓库设置 → Pages → 选择 `Deploy from a branch` → 选择 `main` 分支 → `/root` → 保存
3. 几分钟后就能在 `https://你的用户名.github.io/仓库名/` 访问了

## 设计风格

- 黑金配色，精致奢华
- 响应式设计，支持移动端
- 平滑动画效果
- 包含完整企业站板块：首页、关于、服务、案例、联系
